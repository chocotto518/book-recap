  - 以前の仮のお知らせ（`Toast`）は削除済み
- 書影の入れ方（2026-10-14、仮デザイン。ユーザーの指定「撮る・選ぶ・貼り付けを横並び、切り抜きは四角だけ」）
  - 書影の下にアイコン＋文字のボタンを横に 3 つ（各 64×58、間 8px、文字 12px・グレー、アイコンの線は 1.5px）。アイコンは `public/icons/camera.svg`・`image.svg`（Lucide、仮）と `clipboard-paste.svg`（ユーザー支給）を CSS の mask で文字色に塗る
  - 「撮る」：`<input capture="environment">` で背面カメラを直接開く。指で操作する端末（`pointer: coarse`）だけ表示（PC では「選ぶ」と同じになるため）
  - 「選ぶ」：端末の画像を選ぶ（書影の枠のタップも同じ）。書影の枠の「タップで画像を選択」の文字は消した（読み込み中だけ「読み込み中…」を出す）
  - 「貼り付け」：`navigator.clipboard.read()`（使えないブラウザでは出さない）。iPhone は Safari の「ペースト」確認をはさむ（閉じたら何もしない）。PC はモーダルを開いている間 Ctrl+V / ⌘V でも可（画像のときだけ。文字の貼り付けは邪魔しない）。コピーした画像は端末内のデータなので CORS にかからない
  - どの方法でも、入れた画像は切り抜き画面（`components/CoverCropDialog`）を通る：入力モーダルの上に重なるポップアップ。はじめは画像全体を囲んだ状態（そのまま「決定」なら切り抜かない）。4 隅のつまみで大きさ、枠の中をなぞって位置を動かす。比率は自由。「キャンセル」で書影は変わらない。切り抜いた部分を長辺 900px の JPEG にして保存（`state/covers.ts` の `cropToDataUrl`）
- 書き出しのボタン（2026-10-14 変更）：「端末に保存」「Xで共有」→「端末に保存する」「共有する」

  - iPhone は保存も共有も同じ共有シートになり違いが分からないため、**iPhone はボタン 1 つ「保存する」、Android・PC は 2 つ**（ユーザーの決定）。iPhone は共有シートで X などを選んでも出るので、見出しを「完了しました！」にしている（Android・PC は「端末に保存しました！」）
