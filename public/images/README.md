# images

Figma から書き出して配置する画像（`cover-placeholder.svg` 以外は 1080×1440 の 3:4）

見本の書影（格子柄だった部分）は、Figma の書き出しに `cover-placeholder.svg` を描き込んで差し替えている。Figma から書き出し直すときは、書影の枠もこの SVG にしておく。

## テンプレート設定 › 感想の有無

| ファイル名 | 用途 |
| --- | --- |
| `template-list.png` | 「感想を書く」のサムネイル |
| `template-grid.png` | 「感想を書かない」のサムネイル |

## テンプレート設定 › 作品数の選択

| ファイル名 | 用途 |
| --- | --- |
| `count-list-4.png` 〜 `count-list-1.png` | 感想あり（リスト型）4冊〜1冊のサムネイル |
| `count-grid-6.png` 〜 `count-grid-1.png` | 感想なし（グリッド型）6冊〜1冊のサムネイル |

## 書影が未設定の枠

| ファイル名 | 用途 |
| --- | --- |
| `cover-placeholder.svg` | 書影を設定していない枠の見本（作品の登録の枠、入力モーダル、プレビュー）。枠いっぱいに敷き詰める（はみ出た部分は切る） |

## 編集 › 投稿情報

| ファイル名 | 用途 |
| --- | --- |
| `post-info-list-4.png` | テーマ・ユーザー名がどこに入るかの説明図の見本：感想あり（リスト型）4 冊。見本がまだないテンプレートでもこれを出す |
| `post-info-grid-1.png` 〜 `post-info-grid-5.png` | 同：感想なし（グリッド型）1〜5 冊 |

いずれもユーザー支給の 1080×1440 を 585×780 に縮小（画面では 195×260）。テーマ・ユーザー名の文字の位置はすべて同じ（指す線は共通）
